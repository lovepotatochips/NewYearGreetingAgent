## 接口概述

### 基础信息

- **接口协议**：HTTP/HTTPS
- **数据格式**：JSON
- **字符编码**：UTF-8
- **API版本**：v1.0.0
- **基础URL**：http://localhost:8003

### 接口分类

| 模块 | 路径前缀 | 说明 |
|------|---------|------|
| 认证模块 | /api/auth | 用户登录、注册、信息获取 |
| 对话模块 | /api/conversations | 对话管理和消息交互 |
| 祝福模块 | /api/greetings | 祝福生成和优化 |
| 工具模块 | /api/tools | 实用工具（习俗、礼仪、礼物等） |

## 通用说明

### 请求头

所有需要认证的接口都需要在请求头中携带Token：

```
Authorization: Bearer {access_token}
```

### 通用请求参数

| 参数名 | 类型 | 说明 |
|-------|------|------|
| skip | int | 分页偏移量，默认0 |
| limit | int | 每页记录数，默认20 |

### 通用响应格式

#### 成功响应

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

#### 错误响应

```json
{
  "detail": "错误信息"
}
```

### 日期格式

所有日期时间字段使用ISO 8601格式：

```
YYYY-MM-DDTHH:mm:ss.sssZ
```

## 认证接口

### 1. 用户登录

#### 接口信息

- **接口路径**：POST /api/auth/login
- **接口描述**：用户登录接口，支持手机号或openid登录
- **是否需要认证**：否

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| phone | string | 否 | 手机号（phone和openid二选一） |
| openid | string | 否 | 微信openid |
| username | string | 否 | 用户昵称（phone登录时可选） |

#### 请求示例

**手机号登录**

```json
{
  "phone": "13800138000"
}
```

**微信登录**

```json
{
  "openid": "wxopenid123456"
}
```

#### 响应参数

| 参数名 | 类型 | 说明 |
|-------|------|------|
| access_token | string | 访问令牌 |
| token_type | string | 令牌类型，固定为"bearer" |
| user | object | 用户信息 |
| user.id | int | 用户ID |
| user.username | string | 用户名 |
| user.membership_type | string | 会员类型（free/vip） |
| user.is_active | boolean | 是否激活 |

#### 响应示例

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxIiwiZXhwIjoxNzA0MDY0ODAwfQ.example",
  "token_type": "bearer",
  "user": {
    "id": 1,
    "username": "1380****8000",
    "membership_type": "free",
    "is_active": true
  }
}
```

### HTTP状态码

| 状态码 | 说明 |
|-------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |

| 404 | 资源不存在 |
| 422 | 数据验证失败 |
