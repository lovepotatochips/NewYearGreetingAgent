## 项目概述

### 项目背景

拜年助手是一款面向2026丙午马年的智能春节祝福助手，利用AI技术为用户提供祝福文案生成、优化、习俗咨询、礼仪指导等一站式服务。项目旨在解决春节拜年时文案匮乏、风格单一、礼仪困惑等问题。

### 项目意义

1. **社会价值**：传承和弘扬中华传统文化
2. **用户价值**：提供便捷、高质量的拜年服务
3. **商业价值**：打造春节祝福领域的新兴品牌
4. **技术价值**：探索AI在垂直领域的应用

### 项目范围

- 前端：Web应用、移动端H5
- 后端：API服务、业务逻辑
- AI服务：文案生成、智能对话
- 数据库：用户数据、业务数据
- 第三方集成：OpenAI、微信、支付

## 技术方案

### 技术架构

#### 整体架构

采用前后端分离的微服务架构：

```
用户层（Web/H5/小程序）
    ↓
前端应用层（Vue 3 + Vite）
    ↓
网关层（Nginx + API网关）
    ↓
应用服务层（FastAPI）
    ↓
数据层（SQLite/MySQL + Redis）
    ↓
外部服务（OpenAI/微信/支付）
```

#### 前端架构

- **框架**：Vue 3 Composition API
- **状态管理**：Pinia
- **路由**：Vue Router 4
- **UI组件**：Element Plus
- **构建工具**：Vite 5
- **HTTP客户端**：Axios

#### 后端架构

- **Web框架**：FastAPI
- **异步支持**：async/await
- **ORM**：SQLAlchemy 2.0
- **数据验证**：Pydantic
- **认证**：JWT
- **ASGI服务器**：Uvicorn

#### 数据库架构

- **主数据库**：SQLite（开发）/ MySQL（生产）
- **缓存**：Redis
- **对象存储**：本地文件 / OSS

### 开发规范

#### 代码规范

**前端代码规范**：

1. **命名规范**：
   - 组件名：大驼峰（PascalCase）
   - 变量名：小驼峰（camelCase）
   - 常量名：大写下划线（UPPER_SNAKE_CASE）

2. **文件组织**：
   - 每个组件一个文件
   - 按功能模块组织
   - 统一的文件命名

3. **代码风格**：
   - 使用ESLint进行代码检查
   - 使用Prettier进行代码格式化

2. **文件组织**：
