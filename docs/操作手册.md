## 系统简介

拜年助手是一款面向2026丙午马年的智能春节祝福助手，通过AI对话帮助用户快速生成各种拜年文案、优化文案、查询春节习俗、获取礼仪指导等。

### 主要功能

- AI智能对话：自然语言交互，理解用户需求
- 祝福文案生成：针对不同人群、风格、格式生成个性化祝福
- 文案优化：对已有文案进行润色和改进
- 实用工具：习俗问答、礼仪指导、礼物推荐、红包建议等
- 会员体系：普通用户和VIP用户，享受不同服务

### 二、AI智能对话

#### 功能概述
通过自然语言与AI对话，获取各种拜年相关的帮助和建议。

#### 使用步骤

1. **进入对话界面**
   - 点击首页的"AI对话"按钮
   - 进入智能对话页面

2. **开始对话**
   - 在输入框中输入问题或需求
   - 点击发送按钮或按回车键
   - AI会即时回复

3. **常见提问示例**

   **生成祝福语**
   ```
   帮我生成给长辈的拜年文案
   我想给领导写一条正式的祝福
   给朋友发个幽默的拜年短信
   ```

   **优化文案**
   ```
   帮我优化这段文案：祝您新年快乐，万事如意
   把这段话改成高情商版本
   ```

   **习俗问答**
   ```
   除夕有什么习俗？
   春节为什么要贴春联？
   马年有什么特别的讲究？
   ```

   **礼仪指导**
   ```
   拜年要注意什么礼仪？
   敬酒有什么讲究？
   给领导拜年要注意什么？
   ```

   **其他需求**
   ```
   推荐一些适合送长辈的礼物
   红包给多少合适？
   年夜饭吃什么好？
   ```

4. **查看历史对话**
   - 对话记录会自动保存
   - 可以在左侧对话列表查看历史
   - 点击任意对话可以继续交流

#### 使用技巧

- **表达清晰**：尽量清楚地描述您的需求
- **提供细节**：说明祝福对象、风格偏好等，获得更精准的结果
- **多轮对话**：可以连续提问，AI会记住上下文

### 三、祝福生成

#### 功能概述
根据指定的参数，快速生成符合要求的拜年祝福文案。

#### 使用步骤

1. **进入祝福生成页面**
   - 点击首页的"祝福生成"按钮

2. **选择生成参数**

   **目标人群**（必选）
   - 长辈：正式、尊重、传统
   - 领导：商务、正式、得体
   - 同事：友好、亲切、适度
   - 朋友：轻松、活泼、幽默
   - 老师：尊敬、感恩、温馨
   - 通用：百搭、适用广泛

   **文案风格**（必选）
   - 正式稳重：适合长辈、领导等正式场合
   - 高情商：巧妙表达，让人倍感温暖
   - 简短高级：言简意赅，格调高雅
   - 幽默搞笑：轻松愉快，适合朋友
   - 温暖走心：情感真挚，打动人心
   - 古风文雅：诗意盎然，文化气息浓厚
   - 商务官方：正式得体，适合工作场合
   - 可爱俏皮：活泼可爱，适合年轻人

   **文案格式**（必选）
   - 短句：1-2句话，简洁明了
   - 长文：段落式，内容丰富
   - 对联：对联形式，传统韵味
   - 朋友圈：适合社交媒体发布
   - 视频文案：适合视频配文
   - 红包封面：适合红包备注

   **关键词**（可选）
   - 输入需要包含的关键词，如：健康、平安、事业、家庭等

   **生成数量**（可选）
   - 选择一次生成的文案数量，默认为3条

3. **点击生成按钮**
   - 系统会根据您的选择生成祝福文案
   - 生成过程通常在1-3秒内完成

4. **查看和使用生成的文案**

   **查看文案**
   - 生成的文案会显示在结果区域
   - 每条文案都可以独立查看

   **复制文案**
   - 点击"复制"按钮
   - 文案会自动复制到剪贴板
   - 可以直接粘贴使用

   **优化文案**
   - 点击"优化"按钮
   - 可以调整风格或长度
   - 获得更满意的版本

   **收藏文案**
   - 点击"收藏"按钮
   - 保存到个人收藏夹
   - 方便日后查看和使用

5. **示例操作**

   **场景：给长辈发送新年祝福**

   步骤：
   - 目标人群：选择"长辈"
   - 文案风格：选择"正式稳重"
   - 文案格式：选择"长文"
   - 关键词：输入"健康、长寿"
   - 点击"生成"

   结果示例：
   ```
   尊敬的长辈，值此新春佳节之际，晚辈向您致以最诚挚的祝福。
   祝您在新的一年里身体健康，福寿安康，笑口常开，万事如意。
   感谢您多年来的关爱与教导，愿您享受天伦之乐，幸福美满！
   ```

### 四、文案优化

#### 功能概述
对已有的文案进行优化，使其更加得体、优美或符合特定风格。

#### 使用步骤

1. **进入优化功能**
   - 在祝福生成页面，点击"优化"按钮
   - 或在对话中直接提出优化需求

2. **输入待优化文案**
   - 将需要优化的文案粘贴到输入框
   - 或在对话中直接发送文案

3. **选择优化方向**

   **风格调整**
   - 改变文案的整体风格
   - 如：正式改为温馨，简短改为详细

   **长度调整**
   - 缩短：精简内容，突出重点
   - 加长：丰富内容，增加细节
   - 保持：保持原长度，仅优化表达

   **人群适配**
   - 将文案调整适配不同人群
   - 如：从朋友版本改为长辈版本

4. **查看优化结果**
   - 系统会提供优化后的文案
   - 可以对比原文和优化版本

5. **使用优化后的文案**
   - 复制使用
   - 继续优化
   - 保存收藏

#### 示例

**原文**：祝您新年快乐

**优化为高情商版本**：
```
新的一年，愿您在奔赴未来的路上，有着生生不息的热爱。
愿所有的不期而遇，都成为美好的开始。
新年快乐，万事胜意！
```

  - 敬酒词：简短得体，表达敬意
  - 举杯姿势：双手持杯，低于对方

- 职场拜年
  - 给领导拜年：正式得体，表达感谢
  - 给同事拜年：友好亲切，适度轻松
  - 客户拜年：商务正式，表达合作意愿

- 红包礼仪
  - 给长辈：金额适中，表达敬意
  - 给晚辈：根据惯例，表达关爱
  - 避免禁忌：避免不吉利的数字

## 常见问题

### Q1：如何开始使用？

**A**：
1. 打开浏览器访问系统地址

### Q2：生成的文案可以直接使用吗？

**A**：
可以。系统生成的文案已经过优化，直接使用即可。如果您希望更加个性化，可以使用"优化"功能进行调整。

**A**：
1. 明确目标人群和场景

**A**：
- 普通用户：每日有50次使用限制，可以使用基础功能

## 使用技巧

### 技巧1：善用关键词

在生成祝福时，添加具体的关键词可以获得更精准的结果。

**示例**：
- 不加关键词：给长辈的祝福

---

### 技巧2：多轮对话

在AI对话中，可以连续提问，AI会记住上下文。

**示例**：
```

用户：这个太正式了，改成轻松一点的
AI：[重新生成更轻松的版本]
```

---

### 技巧3：收藏常用文案

将常用的祝福文案收藏起来，方便快速使用。

---

### 技巧4：批量生成

VIP用户可以批量生成祝福，提高效率。

---

### 技巧5：组合使用工具

将多个工具组合使用，获得更好的效果。

**示例**：
1. 先用祝福生成创建基础文案
2. 再用优化功能调整风格
3. 最后根据习俗问答添加文化元素

---

### 技巧6：提前准备

在春节前提前准备好各类祝福文案，到时直接使用。

### 技巧7：个性化定制

在生成祝福时，加入个性化的信息，如对方的名字、共同的回忆等。

### 技巧8：注意时效
