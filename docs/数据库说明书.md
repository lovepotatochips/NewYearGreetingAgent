## 数据库概述

### 数据库选择

本项目支持两种数据库：

| 数据库 | 使用场景 | 优势 |
|--------|----------|------|
| SQLite | 开发环境 | 轻量级、无需配置、零部署 |
| MySQL | 生产环境 | 高性能、高并发、成熟稳定 |

### 数据库位置

- **开发环境**：`backend/newyear_greeting.db`
- **生产环境**：根据服务器配置


## 数据库连接

### 连接配置

**代码位置**：[database.py](file:///d:/project/NewYearGreetingAgent/backend/app/core/database.py)

```python
from sqlalchemy import create_engine
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker
from .config import settings

engine = create_engine(
    settings.DATABASE_URL,
    pool_pre_ping=True,
    pool_recycle=3600,
    echo=False
)

SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

Base = declarative_base()

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

### 会话管理

**获取数据库会话**：
```python
from .core.database import get_db

def some_function(db: Session = Depends(get_db)):
    # 使用db进行数据库操作
    pass
```

**手动创建会话**：
```python
from .core.database import SessionLocal

db = SessionLocal()
try:
    # 数据库操作
    pass
finally:
    db.close()
```

## 数据操作

### CRUD操作

#### 创建（Create）

```python
from sqlalchemy.orm import Session

def create_user(db: Session, user_data: dict):
    new_user = User(**user_data)
    db.add(new_user)
    db.commit()
    db.refresh(new_user)
    return new_user
```

#### 读取（Read）

```python
from sqlalchemy.orm import Session

def get_user(db: Session, user_id: int):
    return db.query(User).filter(User.id == user_id).first()

def get_users(db: Session, skip: int = 0, limit: int = 100):
    return db.query(User).offset(skip).limit(limit).all()
```

#### 更新（Update）

```python
from sqlalchemy.orm import Session

def update_user(db: Session, user_id: int, user_data: dict):
    user = db.query(User).filter(User.id == user_id).first()
    if user:
        for key, value in user_data.items():
            setattr(user, key, value)
        db.commit()
        db.refresh(user)
    return user
```

#### 删除（Delete）

```python
from sqlalchemy.orm import Session

def delete_user(db: Session, user_id: int):
    user = db.query(User).filter(User.id == user_id).first()
    if user:
        db.delete(user)
        db.commit()
    return user
```

### 关联查询

```python
from sqlalchemy.orm import joinedload

def get_conversation_with_messages(db: Session, conv_id: int):
    return db.query(Conversation)\
        .options(joinedload(Conversation.messages))\
        .filter(Conversation.id == conv_id)\
        .first()
```

